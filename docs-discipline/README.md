## 1. 共用约定（全 11 项一致）

| 项 | 约定 |
|---|---|
| 公共标志 | `--self-test` / `--json`（`--json` 为保留标志，当前各脚本以人类可读表格为主）· 各脚本内另有帮助文本，跑一次不带参数或看脚本头部注释即可 |
| 退出码 | `0` 判通过 · **`3` 判不过**（有命中 / 不符 / 缺项）· `2` 用法错 · `1` 内部错误。**`scan-four` 例外：恒 `0`**（机器门恒 `report`） |
| 收尾 | 一律 `process.exitCode = n`，**禁用 `process.exit()`**（Windows + undici 概率崩 libuv 断言） |
| 写动作 | 默认 **dry-run**；真写须显式 `--apply`（且 `archive-rounds` 还须显式 `--archive`） |
| 路径 | 全部支持绝对路径；脚本内部**不含硬编码行号**（`check-caliber` 自测直接扫源码断言这一点） |
| 进程 | 只有 `scan-four` 用 `spawnSync`（薄封装既有四扫工具）；其余脚本**零子进程**，跨脚本调用走 `lib/dispatch.mjs` 的动态 `import`（不受"受限模式下 piped stdio EPERM"影响） |
| junction | 主入口守卫一律 `fs.realpathSync` 双方比对（`isMain`，见 `lib/common.mjs`） |
| 行数口径 | 同时给两套：`gc`（PowerShell `Get-Content` 口径）/ `split`（`split(/\r?\n/)` 口径） |

**文件构成**：`lib/common.mjs`（底座：读档 / 两套行数 / sha / 参数 / 自测脚手架 / 豁免行判据）· `lib/dispatch.mjs`（**唯一**「工具名 → 调用方式」映射，供 `check-rootcause` 与 `selfcheck-rerun` 共用）· 11 个判据脚本 · 本文件。

## 3. 逐项：产物形态 / 取值口径 / 命令

### 3.1 落点自核 —— `check-cites.mjs`

```powershell
node check-cites.mjs --doc <方案档> --report <回修报告> [--section "<本轮章节标题子串>"] [--json]
```

- **产物形态**：`报告行 | 目标 | 引用 | 该行前 60 字 | 反向：引文实际所在 | 判定` → `[汇总] 引用 N · 强核通过 x · 错配（可判红）y · 只报 z` → 错配明细（报告行 / 声明行号 / 引文 / 实际所在行）。
- **取值口径**：引用靠正则抽（`` L<num>「引文」 `` / `「引文」L<num>` / 裸 `L<num>`）；**正向** = 标签 → 行号（目标档第 num 行须含引文，归一：去 `**` / 反引号 / 引号 / 空白）；**反向** = 行号 → 标签（引文在目标档全文搜到的行号须等于声明行号）；无引文的引用 = **无对照物**（只报）；`--section` 之外的历史引用 = **只报不判**（行号随换代必然错位，走订正注）。
- **退出码**：0 无错配 / 3 有错配或引空行 / 2 用法错。

### 3.2 承诺自核 —— `check-promises.mjs`

```powershell
node check-promises.mjs --doc <方案档> --claims <回应表.json|.md> [--json]
```

- **产物形态**：`编号 | 承诺串（截 30） | 期望命中（节 / 行区间） | 实际命中行 | 落在区间内 | 结论` → `[汇总] N 项 · 通过 x · 失败 y`。
- **取值口径**：承诺串与命中行动态搜索（归一后 `includes`）；区间来自回应表声明 —— `§N` ⇒ 该节标题覆盖区间（由标题层级算出），`L a-b` ⇒ 直接用；**命中集合非空但全在区间外** ⇒ 判「射程不符」（不放行）；全档 0 命中 ⇒ 判「承诺未落」。
- **回应表格式**：JSON `{"claims":[{"id":"…","anchor":"…","expect":{"section":"§3","lines":[113,140]}}]}` 或文本行 `- <编号> | <承诺串> | <§3 或 L113-L140>`。
- **退出码**：0 全落在声明区间内 / 3 有承诺未落或射程不符 / 2 用法错或回应表不可读。

### 3.3 口径自核 / 射程自量 —— `check-caliber.mjs`

```powershell
node check-caliber.mjs --scope --doc <方案档>
node check-caliber.mjs --doc <方案档> --changed <改动行集合> [--old <旧值清单.json>]
```

- **产物形态**：
  - 射量模式：`条 | 行号 | [射程] 段（截 90） | 管档类 | 管阶段 | 执行者 | 判定` → `[汇总] 条文 N 条 · 三要素齐备 x · 缺项 y`。
  - 自核模式：`样本行 | 规则 | 相关载体 | 新口径证据串 | 判定` + 失真既有行明细 → `[汇总] 样本 N 条 · 未重写 M`。
- **取值口径（三条写死）**：① **证据串取自本轮新口径文本**（从改动行现抽 `` `…` `` / `**…**`），**禁沿用旧串**、不预置任何黑名单；② **动态定位**（条目 / 节 / 载体全部现算；脚本内无硬编码行号 —— 自测直接扫源码断言）；③ **命中须落在声明的行区间**内。**样本集 = 本轮改动行 ∪ 因新规则而失真的既有行**（同一行出现同族两个不同数值 ⇒ 判该既有行失真，自动并入样本集）。
- **三要素词表**（在本文件顶部常量，改口径改这里）：`RE_DOCFACE` 管档类 / `RE_STAGE` 管阶段 / `RE_WHO` 执行者。
- **退出码**：0 三要素齐备（或）无未重写载体 / 3 有缺项或未重写 / 2 用法错。

### 3.4 旧值残留扫描 —— `check-residue.mjs`

```powershell
node check-residue.mjs --doc <方案档> --report <回修报告> --snapshot <回修前快照目录> [--values <补充清单.json>] [--json]
```

- **产物形态**：`黑名单来源 + 自动收割到的旧 sha16 / 旧数字族` → **展示面**（逐处列出命中，含"本列表不作为待核文本"的明确声明）→ **判定面**（方案档非豁免行 × 旧 sha16）→ `[汇总] 判定面命中 N · 展示面 M`。
- **取值口径**：黑名单**由回修前快照的 `before\*.md` 自动收割**（sha16 / 重计数累计 N 次 / 数字族），**禁手工枚举**；判定面只判 sha16（数字族 / 计数只进展示面，避免"合法引用历史实测值"被误判）；**豁免行（= 展示面）**：含「订正注 / 订正说明」· 位于 §8 修订记录或 §9.1 内 · 含「快照 / before / STAMP」· 位于档头引述块内 · 含「送审件 / 上一版 / 旧值 / 历史 / 实测」；**射程例外**：回修报告整档属展示面（它的体例就要列旧值）⇒ 解掉"要求 0 命中却必须列出旧值"的自指矛盾。
- **退出码**：0 判定面 0 命中 / 3 判定面有残留 / 2 用法错或快照不可读。

### 3.5 自述核对 —— `check-selfclaim.mjs`

```powershell
node check-selfclaim.mjs --report <回修报告> --diff <本轮 diff> [--section "<本轮章节标题子串>"] [--json]
```

- **产物形态**：`报告行 | 自述（截 90） | 可核 token | 文件名 | diff 实证 | 结论` → `[汇总] 自述行 N · 有实证 x · 相抵/无实证 y · 无对照物 z`。
- **取值口径**：自述行靠触发词匹配（已改 / 已重写 / 已补 / 已加 / 已闭合 / 已落 / 已删 / 已登记 / 逐字一致 / 未变 / 无改动）；token 靠正则抽（sha16 / N 行 / N B / N 条 / N 次）；**「未变」型自述反向核** —— diff 头里出现该文件 ⇒ 判相抵（这正是「报告说改了、正文没改」族的正解）；`--section` 之外的章节不扫。
- **退出码**：0 自述与 diff 一致 / 3 有相抵或无实证 / 2 用法错。

### 3.6 根因回测 —— `check-rootcause.mjs`

```powershell
node check-rootcause.mjs --doc <方案档> --families <族表.json> --fixture <夹具目录> [--json]
```

- **产物形态**：`族 | 成因（机制层，截 46） | 改进措施（落点 → 方案档实测行） | 回测（工具 → 判定） | 结论` → `[汇总] 族 N · 回测成立 x · 未成立 y`。
- **取值口径**：成因表**缺任一要素**（成因 / 改进落点 / 夹具）⇒ 判本族「回修未完成」，不静默跳过；改进落点须能在方案档**动态定位**（`第 N 条` / `§N` / 字面），定位不到同样判未完成；**回测 = 拿历史实例或夹具喂改进后的判据，必须判不过**（判过 ⇒ 回测不成立）。
- **族表格式**：`{"families":[{"id":"F1","成因":"…","改进落点":"第 7 条","fixture":{"tool":"check-selfclaim","args":{"report":"bad.md","diff":"d.txt"}},"expect":"FAIL"}]}`，其中 `args` 里的相对路径按 `--fixture` 目录解析。
- **退出码**：0 全部族回测成立 / 3 有族未成立 / 2 用法错。

### 3.7 ⑤失败环复跑 —— `selfcheck-rerun.mjs`

```powershell
node selfcheck-rerun.mjs --record --doc <送审件> --manifest <清单.json> --out <产物目录>
node selfcheck-rerun.mjs --replay --doc <送审件> --manifest <清单.json> --artifacts <产物目录> [--stage1 <改动行集合>]
```

- **产物形态**：`判据 | class | 产物记录的送审件 sha16 | 当前 sha16 | sha 一致 | 自核判定 | 复跑判定 | n（自核/复跑） | 结论` → `[汇总] 产物 N 项 · 一致 x · 不一致 y`。
- **取值口径**：① **比对前先校验产物记录的送审件 sha = 当前送审件 sha**（不符 ⇒ 判「自核未执行」，绝不用过期读数当基准）；② **计数类产物（class=count）不作基准**，只比判定；非计数类（class=exact）逐条比判定 + 计数 `n`；③ 复跑参数 = 清单 `args` **逐字复用**；`--stage1` 只作留痕、不作数值基准。
- **产物文件格式**（`<out>\NN-<tool>.json`）：
  ```json
  {"tool":"check-cites","args":{…},"class":"exact","docPath":"…","docSha16":"…","hash":"…","at":"…","verdict":"PASS","n":0,"detail":"…","stage1":null,"stage1Sha16":null}
  ```
- **退出码**：0 产物与复跑一致 / 3 有 sha 不符、判定不一致或产物缺失 / 2 用法错。

### 3.8 体量核 —— `check-volume.mjs`

```powershell
node check-volume.mjs --doc <审核档|回修报告> --round <N|last> [--json]
```

- **产物形态**：`档路径 · sha16 · 全档行数（gc / split）· 字节` → `章节：第 N 轮 · 起止行号 · 行数 · 区间字节` → 判定①单轮章节 ≤ 61 440 B → 判定②全档 ≤ 800 行 → 判定③搬迁触发（是 / 否）→ `[汇总]`。
- **取值口径**：区间 = **标题行（含）→ 章节正文最后一行（含）**，**不含**其后 `---` 与空行；行间以 **LF** 拼（CRLF 会每行多 1 字节 —— 第 10 轮实测差 309 B = 章节行数）；全档行数给两套口径。**判定②超限不是"体量核判不过"，而是搬家动作的触发条件**（执行者 = 脚本）。
- **退出码**：0 单轮章节在限内 / 3 单轮章节超限 / 2 用法错或找不到章节。

### 3.9 轮次搬家 —— `archive-rounds.mjs`

```powershell
node archive-rounds.mjs --doc <审核档> --keep-lines 800                    # dry-run（默认）
node archive-rounds.mjs --doc <审核档> --keep-lines 800 --apply --archive <归档目录>
```

- **产物形态**：`档路径 · 行数两口径 · 字节 · sha16 · 限额判定` → 拟搬轮次表（`序 | 轮次 | 区间 | 行数 | 字节 | 单轮是否超限`）→ 搬家后行数（预计）· 指针行落点（预计）· 指针写法 → `[汇总]`。
- **取值口径**：整轮章节靠顶层 `# 第 N 轮审核|回修` 动态定位（复用 `check-volume` 的区间口径）；**最旧优先**逐轮搬直到全档 ≤ `keep-lines`；**只搬整轮、不改内容**，正文留**一行指针**（指针必须写「引用请按『轮次 + 编号』，勿按行号」）；**默认 dry-run**，`--apply` 须同时给 `--archive`，写前自动备份 `<archive>\before\<原档名>` 并打印一键回滚命令；**单轮章节自身 > 61 440 B ⇒ 拒绝搬家**（先瘦身 / 拆轮）。
- **退出码**：0 计划生成成功 / 搬家成功；2 用法错、缺 `--archive`、章节块定位失败；3 目标档读取失败。

### 3.10 轮次单调 —— `check-rounds.mjs`

```powershell
node check-rounds.mjs --doc <审核档|回修报告> [--ledger <台账 json>] [--json]
```

- **产物形态**：`序 | 轮次 | 首见行号 | 首见标题（截 60）` → `[序列]` → `[判定①单调 +1]` → 声明表（`轮次 | 重计数 | 行号 | 原文`）+ `[判定②声明双序列单调 +1]` → `[判定③台账投影]` → `[汇总]`。
- **取值口径**：轮次靠标题行与「本轮 = 第 N 轮（重计数第 M 轮）」声明**动态抽取**；同一轮出现多次（回指 / 同轮多章节）**只取首见**（避免回指被误判成跳号）；**台账 `roundNo` 只是投影** —— 与审核档不符 ⇒ 以审核档为准，脚本只提示。
- **退出码**：0 单调通过 / 3 有断点或声明序列不单调 / 2 用法错。

### 3.11 文档纪律四扫 —— `scan-four.mjs`

```powershell
node scan-four.mjs --doc <档> [--defs 4.4,5,8] [--lists 5,8,12] [--ignore-own-headings] [--allow-doc-prefix N] [--json]
```
